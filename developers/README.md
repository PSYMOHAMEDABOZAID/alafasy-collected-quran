# مصحف مشاري العفاسي المجمع — دليل المطورين

## الهدف

إضافة تلاوة **«مشاري العفاسي – مصحف مجمع»** إلى تطبيق قرآن جديد مع صوتيات 114 سورة وتوقيتات الآيات. المصدر إصدار GitHub مستقل عن مشروع «سميع»، وتستطيع التطبيقات استخدام الروابط مباشرة دون نسخ مجلد الصوتيات إلى المشروع — **إذا ظلت الأصول متاحة وكان الاستخدام مسموحًا حقوقيًا**.

### 1. رابط الإصدار

<https://github.com/PSYMOHAMEDABOZAID/alafasy-collected-quran/releases/tag/v1.0.0>

### 2. روابط الملفات

```text
BASE = https://github.com/PSYMOHAMEDABOZAID/alafasy-collected-quran/releases/download/v1.0.0
MP3  = BASE/NNN.mp3
JSON = BASE/timings-NNN.json
```

استبدل `NNN` برقم السورة بثلاث خانات (`001` إلى `114`). مثال: `002.mp3` و`timings-002.json` لسورة البقرة.

> هذه **روابط تنزيل ملفات ثابتة** وليست API قابلة للاستعلام. GitHub Releases ليس خادم بث مضمون الخدمة أو SLA. قد توجد قيود وصول أو تحميل أو CORS أو تغيّرات في الأصول؛ ضع خطة احتياطية ملائمة للاستخدام الإنتاجي.

### 3. شكل التوقيتات

ملف التوقيتات مصفوفة JSON بها عناصر بالشكل:

```json
[
  {"ayah":1,"start_time":0,"end_time":5000},
  {"ayah":2,"start_time":5000,"end_time":9000}
]
```

**الأرقام أعلاه توضيحية فقط وليست توقيتات حقيقية**. `start_time` و`end_time` بالمللي ثانية من بداية ملف MP3 الخاص بالسورة، و`ayah` رقم الآية داخل السورة، وليس رقمًا عالميًا. يجب تنفيذ `timeMs = currentPositionSeconds * 1000` ثم اختيار الآية التي يقع وقت التشغيل بين بدايتها ونهايتها.

### 4. دعم الويب وCORS

- ملفات MP3 يمكن غالبًا إسنادها إلى `<audio src="...">` أو مشغّل متوافق.
- `fetch()` مباشر من المتصفح لملفات JSON على نطاق آخر **قد يفشل بسبب CORS**؛ مثال Next.js يوفّر مسار خادم `GET /api/alafasy-collected/timings/:surah` لجلب JSON من GitHub بشكل موثوق أكثر دون تجاوز قيود المتصفح. هذا المسار جزء من **تطبيق المطوّر** وليس خدمة مستضافة في مستودع العفاسي.
- جرّب التحميل على هاتف حقيقي وعلى الشبكة المطلوبة قبل النشر.

### 6. الاعتماد والحقوق

- **اسم التجميع:** المصحف المجمع للقارئ مشاري بن راشد العفاسي (تجميعي).
- **سنة التسجيل:** غير موثقة، وقد تختلف بين السور وفق وصف الإصدار.
- **مصدر الملف المعتمد لهذا المشروع:** رابط GitHub Release أعلاه.
- **الترخيص:** ناشر التجميع أفاد بأن الملفات مجانية الوصول والتنزيل؛ ولم تثبت هنا رخصة صريحة تمنح إعادة توزيع التسجيلات الأصلية أو استخدامها تجاريًا. راجع [بيان الحقوق والمصادر](RIGHTS_AND_SOURCES.md) قبل أي استعمال عام.
- **مهم:** ملفات التوقيتات مستخرجة/مرفقة بالتجميع؛ لا يدّعي التوثيق تدقيق كل آية سمعيًا. افحص المطابقة بنفسك في تطبيقك.

### 7. التحقق

نفّذ `python3 developers/scripts/check_release.py --sample-json` من جذر المستودع؛ أو ادخل Actions وشغّل **Check developer release assets**. إذا فشل الاختبار لا تفترض أن الروابط كلها صالحة.
