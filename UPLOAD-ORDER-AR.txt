تعليمات رفع قسم «للمطورين | Developer API»

المستودع: https://github.com/PSYMOHAMEDABOZAID/alafasy-collected-quran

1) افتح ZIP وفك الضغط.
2) ارفع الملف DEVELOPERS.md (في جذر المستودع).
3) ارفع مجلد developers كاملًا بمساراته الداخلية.
4) ارفع ملف .github/workflows/check-developer-assets.yml مع الحفاظ على المسار.
5) احفظ Commit على main.
6) افتح Actions -> Check developer release assets -> Run workflow وشاهد نتيجة الفحص (يتطلب اتصال GitHub).

لإظهار القسم من README الرئيسي، أضف هذا السطر إلى README الموجود (دون حذف محتواه):

[للمطورين | Developer API](DEVELOPERS.md)

مهم: هذا الأرشيف لا يحتوي ملفات MP3 ولا يغيّر إصدار v1.0.0 ولا ملفات التشغيل السابقة.
مهم: الرابط الصوتي/التوقيتي المباشر لم يُختبر حاليًا من بيئة إعداد التوثيق.
مهم: لا تضع رخصة مفتوحة لتسجيلات الآخرين قبل التحقق من الحقوق والأذونات.

اذا رفعت عبر GitHub web، تأكد أن المجلدات لم تتداخل داخل مجلد إضافي باسم الحزمة.

الحزمة تتضمن 4 منصات وملف فحص آلي. ليست خدمة API مستضافة ولا تحتاج مفتاحًا.
يتطلب Next.js 15/16 route params من نوع Promise (متوافق مع الخطأ السابق في سميع).
قال صاحب المستودع إن التسجيلات مجانية، لكن لم تُقدَّم وثيقة حقوق للتسجيلات الأصلية؛ لا نضع لها ترخيصًا قانونيًا افتراضيًا.
لرفع المحتويات من واجهة GitHub، حافظ على جذر المجلدات (لا ترفع مجلد الحزمة نفسه). مجلد .github قد يكون مخفيًا على ماك: Cmd+Shift+.
